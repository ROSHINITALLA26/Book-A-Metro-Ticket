# Book-A-Metro-Ticket
Book A Metro Ticket ServiceNow application
## 🚇 Metro Ticket Booking System

A ServiceNow-based Metro Ticket Booking application with automated fare calculation,
request tracking, booking record creation, and QR-based ticket verification.

### 🎥 Project Demo

[▶️ Watch the Project Demo]([YOUR_GOOGLE_DRIVE_LINK](https://drive.google.com/file/d/1HHIN9mJaFZIL6zIJfFRJePf8RtHEU2he/view?usp=sharing))

### ✨ Features

- Metro ticket booking through Service Portal
- Automatic fare calculation
- Request and RITM generation
- Automated booking record creation
- Metro Ticket Booking database table
- QR-based ticket verification
- Public ticket verification for station authority
